# Project Glossary

- **Authorship Attribution**: Classification task identifying which LLM authored a given text excerpt.
- **Balanced Accuracy**: Arithmetic mean of sensitivity (recall) across all classes.
- **GroupKFold**: Cross-validation splitter ensuring no group (here `prompt_id`) appears in both train and validation splits.
- **Stylometry**: Extraction and quantitative analysis of linguistic and writing style markers.
- **G0–G5 Gates**: Deterministic harness verification checkpoints.
